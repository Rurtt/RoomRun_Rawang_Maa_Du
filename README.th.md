# ระวังหมาดุ (Rawang Maa Du)

[English](README.md) | **ภาษาไทย**

เกมวิ่งบนเบราว์เซอร์ที่เล่นด้วยการวิ่งอยู่กับที่ หมาจรตัวใหญ่ไล่เด็กคนหนึ่งในซอยตอนกลางคืน วิ่งจริงให้เร็วขึ้น เด็กในเกมก็หนีได้ ถ้าช้าลง หมาก็ตามทัน

เกมนี้เป็นเกมสาธิตของ **RoomRun** จอยควบคุมไร้สายแบบถือมือ 1 คู่ (มือละแท่ง) ตัวสินค้าคือจอย จุดขายคือทำให้การออกกำลังกายแบบคาร์ดิโอสนุกขึ้น ด้วยเกมที่ควบคุมด้วยการขยับร่างกายจริง และเกมนี้คือตัวอย่างว่าเล่นแล้วรู้สึกยังไง

> **สถานะ: ต้นแบบ (proof of concept)** ตัวจอยจริง (ESP32-C3 + MPU6050) ยังไม่ได้สร้าง ตอนนี้ใช้ **โทรศัพท์ 2 เครื่อง ถือมือละเครื่อง แทนจอย** และเล่นด้วยคีย์บอร์ดได้สำหรับทดสอบ ระบบตรวจจับท่าทางยังอยู่ระหว่างปรับจูน

## วิธีเล่น

คุณคือเด็กในเกม หมาบอสวิ่งตามหลังด้วยความเร็วคงที่ ความเร็วของคุณมาจากการวิ่งอยู่กับที่ (หรือกดปุ่มสลับ) ยิ่งเร็วยิ่งวิ่งเร็ว วิธีเดียวที่จะนำหน้าหมาได้คือต้องขยับตลอด

- **สิ่งกีดขวาง** ทำให้เสียระยะ แต่ไม่จบเกม:
  - **หมานอน / โอ่งน้ำ**: กระโดดข้าม ถ้าชนหมาที่นอนอยู่ หมาจะตื่นแล้ววิ่งไล่ติดส้นเท้าอยู่พักหนึ่ง
  - **รถเข็นขายของ / ตุ๊กตุ๊ก**: เปลี่ยนเลน ชนรถเข็นแล้วเหรียญหล่นหาย ชนตุ๊กตุ๊กจะมึนนานกว่า
  - ป้ายบนพื้นบอกล่วงหน้า: **สีเหลือง = กระโดด**, **สีแดง = เปลี่ยนเลน**
- **เหรียญ** วางอยู่ตามเลน
- **ฝูงหมาไล่**: ประมาณ 1 นาทีแรก และทุก ๆ ~90 วินาทีหลังจากนั้น จะมีฝูงหมามาไล่ 30 วินาที ทุกอย่างเร็วขึ้น รอดได้จะได้เหรียญโบนัสและหนีห่างจากหมาบอสมากขึ้น เหมือนวิ่งอินเทอร์วัลแบบไม่รู้ตัว
- เกมจบ **เฉพาะตอนหมาบอสตามทัน** แถบด้านบนบอกว่าหมาอยู่ใกล้แค่ไหน

### การควบคุม

| ท่า | โทรศัพท์ (ถือมือละเครื่อง) | คีย์บอร์ด |
|---|---|---|
| วิ่ง | แกว่งแขนเหมือนวิ่งอยู่กับที่ | กด **A** กับ **D** สลับกัน (ยิ่งเร็วยิ่งวิ่งเร็ว) |
| เปลี่ยนเลน | สะบัด **ทั้งสองมือ** ไปทางซ้ายหรือขวาพร้อมกัน | **← / →** |
| กระโดด | สะบัด **ทั้งสองมือ** ขึ้นพร้อมกัน | **Space** |
| เริ่มใหม่ | | **R** |

ปุ่มสำหรับนักพัฒนา: **C** เริ่มฝูงหมาไล่ทันที, **`** (backquote) เปิดแผงปรับค่า

## วิธีรัน

ต้องมี [Node.js](https://nodejs.org/) เวอร์ชัน 20.19+ หรือ 22.12+

```bash
npm install
```

**เล่นด้วยคีย์บอร์ดอย่างเดียว (ในเครื่อง):**

```bash
npm run dev
```

เปิดลิงก์ที่ Vite แสดง (ปกติคือ http://localhost:5173)

**ใช้โทรศัพท์เป็นจอย (หรือให้เพื่อนเล่นจากที่ไหนก็ได้):**

```bash
npm run phone
```

คำสั่งนี้จะ build เกม เปิดเซิร์ฟเวอร์ที่ http://localhost:8787 และเปิด Cloudflare quick tunnel (ฟรี) ให้ได้ลิงก์สาธารณะแบบ `https://….trycloudflare.com`

1. เปิดเกมบนโน้ตบุ๊กหรือคอม (ลิงก์ในเครื่อง หรือลิงก์สาธารณะจากที่ไหนก็ได้)
2. สแกน QR บนหน้าแรกของเกมด้วยโทรศัพท์ทีละเครื่อง เลือกมือซ้ายหรือขวา กดเริ่ม (อนุญาตการเข้าถึงเซ็นเซอร์การเคลื่อนไหว) แล้วถือมือละเครื่อง
3. เริ่มวิ่งอยู่กับที่

ควรรู้:
- คอมเครื่องที่รัน `npm run phone` ต้องเปิดค้างไว้ และลิงก์จะเปลี่ยนทุกครั้งที่รันใหม่
- ตอนนี้มี **ห้องเดียวรวมกัน** ถ้ามีสองคนต่อโทรศัพท์พร้อมกัน โทรศัพท์ของทั้งคู่จะคุมทั้งสองเกม (คนเล่นด้วยคีย์บอร์ดไม่มีปัญหานี้)
- ข้อมูลจากโทรศัพท์วิ่งเส้นทาง โทรศัพท์ → Cloudflare → คอมที่รันเซิร์ฟเวอร์ → Cloudflare → เกม คนที่อยู่ไกลอาจรู้สึกว่ามีดีเลย์
- เซิร์ฟเวอร์บันทึกข้อมูลการเคลื่อนไหวไว้ใน `logs/` (ข้อมูลดิบสำหรับจูนจอยจริง)

## ทำงานยังไง

```
โทรศัพท์ / จอย (เซ็นเซอร์) ──WebSocket──► relay (server/relay.mjs) ──► เกมในเบราว์เซอร์
```

- **เกม**: Three.js, JavaScript ธรรมดา, build ด้วย Vite ส่วน simulation (`src/sim/`) แยกจากส่วนแสดงผล (`src/render/`) และคำนวณทีละสเต็ปคงที่ 120 Hz
- **ตรวจจับท่าทาง** (`src/input/motion.js`): แปลงความเร่งจากการแกว่งแขนเป็นจังหวะก้าว (ความเร็ววิ่ง) การเปลี่ยนเลน และการกระโดด โค้ดเดียวกันนี้จะใช้อ่านค่าจากจอย ESP32 ในอนาคต
- **Relay** (`server/`): เซิร์ฟเวอร์ Node ตัวเล็ก ๆ ที่ส่งไฟล์เกมและส่งต่อข้อมูลจากโทรศัพท์ไปยังเกมผ่าน WebSocket
- **กราฟิก**: ตัวละครและพร็อพสร้างใน Blender ด้วยสคริปต์ Python (`art/blender/*.py`) แล้ว export เป็น GLB

```
src/sim       กติกาเกม: ผู้เล่น หมาไล่ ถนน ฝูงหมา
src/render    ฉาก 3D ตัวละคร ถนน เอฟเฟกต์ HUD
src/input     คีย์บอร์ด โทรศัพท์ ตรวจจับท่าทาง จังหวะก้าว
src/phone     หน้าจอยบนโทรศัพท์ (phone.html)
src/audio     เสียงและเพลง
server        relay + Cloudflare tunnel (npm run phone)
art/blender   สคริปต์สร้างโมเดล 3D
tests         unit tests (npm test)
scripts       replay.mjs: เล่นข้อมูลการเคลื่อนไหวซ้ำเพื่อจูนการตรวจจับ
```

## ข้อจำกัด (ตามจริง)

- ยังไม่ได้สร้างจอยจริง ตอนนี้ใช้โทรศัพท์แทน
- การตรวจจับวิ่ง เปลี่ยนเลน และกระโดดจากการถือในมือ ยังอยู่ระหว่างจูน และยังไม่ได้ทดสอบกับผู้เล่นหลายคน
- เซ็นเซอร์อยู่ที่มือเท่านั้น เกมจึงบอกไม่ได้ว่าขาวิ่งจริงหรือเปล่า
- ไม่มีการอ้างผลด้านสุขภาพหรือฟิตเนส เป็นเกมที่ชวนให้ขยับตัว ไม่ได้วัดอะไรมากกว่านั้น
